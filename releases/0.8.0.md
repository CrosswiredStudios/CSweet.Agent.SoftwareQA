# 0.8.0

Adds owner-assigned private-preview diagnostic triage. QA reads canonical sanitized evidence, analyzes it with an approved model without tools, and files a deduplicated planning ticket only when evidence establishes a defect. Ticket creation copies evidence and requires ordinary board-scoped creation permission.

New finding-read, finding-ticket, work-item-create and work-type-read declarations require upgrade review. Local builds detect sibling WebHost.Contracts and Agent SDK clones; NuGet publication is not needed for development.

Updates the hosting contract dependency to 0.3.0 for the event/recovery release; assigned finding triage and board permission requirements remain unchanged.
